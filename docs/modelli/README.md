# Modelli dei lavori ripetuti

Cinque lavori che si ripetono (contati nella sessione del 6-7/10: circa 84 PR e 83 merge, 233 letture dei log, 23 modifiche di variabili Railway, un recap al giorno). Ogni modello e' sotto una pagina: scopo, dati necessari, passi, formato dell'output, controllo finale, esempio reale.

1. `pr-ci-merge.md`: da codice pronto a merge in `main`.
2. `analisi-log.md`: leggere i log Railway senza sprecare token.
3. Recap mattutino: `docs/recap.md` (gia' esistente, letto dalla routine delle 05:47).
4. `variabili-railway.md`: cambiare una variabile del worker e verificare il deploy.
5. `aggiorna-stato.md`: chiudere una tappa in `STATO.md`.

Regola: se due lavori sono lo stesso lavoro, si uniscono in un modello solo. Le regole generali restano in `CLAUDE.md`, i modelli dicono solo come eseguire.
