# Procedure fisse

Lavori che l'utente chiede spesso, sempre nello stesso formato. Ognuna ha: scopo, input, passi, formato della risposta, esempio reale, controllo finale. Regola: se due lavori sono lo stesso lavoro, si uniscono in una procedura sola. Le regole generali stanno in `CLAUDE.md`; le procedure dicono solo come eseguire.

- `analisi-log.md`: domande sul bot e analisi di moda e radar dai log. Recap mattutino: `docs/recap.md`.
- `ciclo-modifica.md`: dal branch al merge e alla verifica in produzione.
- `controllo-deploy.md`: dopo ogni merge o riavvio.
- `variabili-railway.md`: cambiare una variabile del worker e verificare l'effetto.
- `ricerche-tracker.md`: aggiungere o cambiare ricerche dei due tracker.
- `consumi.md`: banda proxy e quote Gemini.
- `aggiorna-stato.md`: chiudere una tappa in `STATO.md`.
