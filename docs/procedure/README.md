# Procedure fisse

Lavori che l'utente chiede spesso, sempre nello stesso formato. Ognuna ha: scopo, input, passi, formato della risposta, esempio reale, controllo finale.

- `analisi-log.md`: cosa sta succedendo, cosa ha valore (moda e radar).
- `controllo-deploy.md`: dopo ogni merge o riavvio.
- `ricerche-tracker.md`: aggiungere o cambiare ricerche dei due tracker.
- `ciclo-modifica.md`: dal branch alla verifica in produzione.
- `consumi.md`: banda proxy e quote Gemini.
